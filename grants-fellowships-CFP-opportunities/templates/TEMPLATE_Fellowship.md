## ✅ APPLICATION CHECKLIST

### 3-6 Months Before Deadline
- [ ] Identify potential sponsors/mentors
- [ ] Schedule meetings with potential sponsors
- [ ] Review eligibility requirements in detail
- [ ] Identify research topic and develop preliminary ideas
- [ ] Start literature review
- [ ] Collect preliminary data (if needed)
- [ ] Identify institutional resources and support

### 2-3 Months Before Deadline
- [ ] Finalize sponsor/mentor team
- [ ] Draft research plan (Specific Aims first)
- [ ] Develop training plan with sponsor
- [ ] Outline career development activities
- [ ] Identify and contact potential letter writers
- [ ] Request sponsor letter(s)
- [ ] Request institutional letters of support

### 1 Month Before Deadline
- [ ] Complete first full draft of all application components
- [ ] Share draft with sponsor for feedback
- [ ] Share draft with internal reviewers
- [ ] Request biosketches from sponsor/co-sponsors
- [ ] Finalize budget and justification
- [ ] Send letter requests with draft materials to letter writers

### 2-3 Weeks Before Deadline
- [ ] Incorporate feedback from sponsor and reviewers
- [ ] Complete second full draft
- [ ] Proofread and edit
- [ ] Verify all formatting requirements met
- [ ] Confirm reference letters will be submitted on time
- [ ] Submit to institutional pre-award office (if required)

### 1 Week Before Deadline
- [ ] Final revisions
- [ ] Final proofread
- [ ] Verify all required documents included
- [ ] Create submission account (if needed)
- [ ] Upload documents to submission system
- [ ] Verify all uploads are readable
- [ ] Request institutional approval/signature (if required)

### Day of Deadline
- [ ] Final check of submission system
- [ ] Confirm all reference letters received
- [ ] Submit application (aim for 2+ hours before deadline)
- [ ] Save confirmation of submission
- [ ] Thank sponsor, letter writers, and support staff

- [ ] Send thank you notes to sponsor, letter writers, collaborators
