## 📋 How to Use This System

### 1. Adding New Opportunities

**Option A: Use Templates**
1. Copy appropriate template from `templates/`
2. Create new file: `OPPORTUNITY_[###]_[SHORT_NAME]_[YEAR].md`
3. Fill in all sections
4. Add row to `OPPORTUNITIES_TRACKER.csv`
5. Update `calendar/MASTER_DEADLINE_CALENDAR.md`

**Option B: Quick Add**
```bash
# Ask the Grant Writing Agent or Project Manager Agent:
"Add new opportunity: [paste URL or details]"
```

### 2. Checking Deadlines

**Quick check**: Open `calendar/MASTER_DEADLINE_CALENDAR.md`

**Detailed check**: Open individual opportunity files for:
- Eligibility requirements
- Required materials
- Review criteria
- Past winning examples

**Spreadsheet view**: Import `OPPORTUNITIES_TRACKER.csv` to Excel/Google Sheets

### 3. Tracking Progress

Update the `Status` column in `OPPORTUNITIES_TRACKER.csv`:
- `Active` - Currently accepting submissions
- `Monitoring` - Not yet open, but tracking
- `In Prep` - Actively preparing application
- `Submitted` - Application submitted, awaiting decision
- `Awarded` - Won the grant/prize
- `Declined` - Not selected
- `Withdrawn` - We withdrew application
- `Closed` - Deadline passed, not submitted

## 🎯 Priority Scoring System

**Alignment Score (1-10)**
- 9-10: Perfect fit, strongly aligned with research goals
- 7-8: Good fit, mostly aligned
- 5-6: Moderate fit, requires adaptation
- 3-4: Weak fit, significant gaps
- 1-2: Poor fit, not recommended

**Priority Levels**
- ⭐⭐⭐⭐⭐ **CRITICAL**: Must pursue, perfect alignment, high success probability
- ⭐⭐⭐⭐ **HIGH**: Strong candidate, good ROI on application effort
- ⭐⭐⭐ **MEDIUM**: Worth pursuing if capacity allows
- ⭐⭐ **LOW**: Consider only if no higher priorities
- ⭐ **MONITOR**: Track for future, not current priority

## 📊 Opportunity Categories

### By Type
- **Prize Competitions**: Challenge.gov, XPRIZE, foundation prizes
- **Research Grants**: NIH (R01, R21, R61/R33), NSF, foundation grants
- **Fellowships**: Individual investigator awards, career development (K awards)
- **Training Grants**: T32, institutional training programs
- **Conference Grants**: Travel awards, presentation support
- **Pilot Grants**: Internal university, foundation pilot programs

- Substance Use Disorder (SUD)
- Mental Health / Suicide Prevention
- Occupational Health

- Behavioral Economics
- Longitudinal Epidemiology
- Community-Engaged Research
- Arts & Health

### By Agency/Funder
- **Federal**: NIH (NIDA, NIMH, NIAAA, NCCIH), NSF, CDC, SAMHSA

## 📝 Application Checklists

### Before Submitting ANY Application

- [ ] Eligibility verified (institutional, geographic, career stage)
- [ ] Team assembled (if required)
- [ ] All required documents drafted
- [ ] Budget developed and justified
- [ ] Letters of support secured
- [ ] Institutional approvals obtained (IRB, IACUC, conflict of interest)
- [ ] Submission system access verified
- [ ] Formatting requirements met (page limits, font, margins)
- [ ] Internal deadline met (institutional review, 2-5 days before submission)
- [ ] Final proofread completed
- [ ] Submitted with 2+ hours before deadline

### Prize Competition Specific (like NIDA)

- [ ] Team size requirements met (3-5 members for NIDA)
- [ ] Team Leader identified (US citizen/permanent resident)
- [ ] Time commitment feasible (25 hrs/month for NIDA)
- [ ] Idea aligns with funder priorities (SUD for NIDA)
- [ ] Video pitch prepared (if required)
- [ ] Slide deck prepared (if required)
- [ ] All team members committed to mentorship period
